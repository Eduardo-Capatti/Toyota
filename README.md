# 🚗 Toyota — Página Inicial

Página inicial inspirada no site oficial da Toyota, desenvolvida com **HTML5**, **CSS3** e **Bootstrap 5**. Utiliza ícones do **FontAwesome** para ilustrar seções e funcionalidades.

## 📋 Tecnologias Utilizadas

| Tecnologia | Descrição |
|---|---|
| **HTML5** | Estrutura semântica da página |
| **CSS3** | Estilização personalizada e animações |
| **Bootstrap 5** | Framework responsivo e componentes pré-prontos |
| **FontAwesome** | Biblioteca de ícones vetoriais |

## ✨ Funcionalidades

- **Layout responsivo** — adapta-se a desktops, tablets e dispositivos móveis
- **Navbar** — menu de navegação fixo no topo
- **Hero Section** — banner principal com chamada para ação
- **Seção de modelos** — cards com os veículos disponíveis
- **Rodapé** — informações de contato e links úteis

## 🚀 Como Executar

1. Clone este repositório:
   ```bash
   git clone <url-do-repositorio>
   cd <nome-da-pasta>
   ```
2. Abra o arquivo `index.html` no navegador de sua preferência.
3. Pronto! O site não requer servidor — basta abrir diretamente.
